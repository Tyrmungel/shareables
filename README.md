# shareables

Public artifacts shared out from private work, served via GitHub Pages at
[tyrmungel.github.io/shareables](https://tyrmungel.github.io/shareables/).

Each project lives in its own subfolder, synced from that project's own
repo (e.g. from a `presentation/` staging folder there).

| Folder | Source | What it is |
|---|---|---|
| [`agentic-pdlc/`](agentic-pdlc/) | `pm-demo` (pre-rename) | PM take-home: an 8-stage product-decision playbook applied to a real case (Enefit) |
| [`riik-mcp/`](riik-mcp/) | `riik-mcp` | e-Estonia: Open data and API access — Estonian Open Data Atlas (8,515 entries) and eesti.ee API Access Map (46 personal-data endpoints) |
